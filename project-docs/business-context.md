# 业务上下文（Business Context）

## 产品目标

“王晨扬的计算器”是应届机试题交付物，通过可运行桌面程序展示 MVC（模型-视图-控制器）分层和可复核的工程实践。

## 用户与范围

- 用户：使用 Windows 桌面计算器的终端用户和维护者。
- 计算范围：`+`、`-`、`*`、`/`、小数、括号和一元正负号；支持 `CE` 清零与退格；错误输入、括号不匹配和除零提供友好提示。
- v1.1 已有能力：用户名、预设主题和本地背景图配置持久化；图标与固定窗口尺寸。
- 非范围：历史记录、科学计算、网络功能、账户验证和第三方依赖。

## 关键约束

- `src/model/`（模型）不得依赖 Qt 类型；Controller（控制器）负责输入编排，View（视图）只负责渲染。
- 不得改变既有表达式计算语义；解析失败必须返回结构化错误，不向界面抛出未处理异常。
- 流程证据与运行时源码分离，旧 `docs/ai-workflow/` 记录只读保留。

## 风险

- MVC 边界被破坏会导致计算逻辑难以测试。
- 非法表达式和除零可能引发崩溃或错误结果。
- Windows Qt/MSVC 运行时部署不完整会导致终端启动失败。
