## 变更

- `scripts/release/Package-Release.ps1` 第 65 行将 ZIP（压缩包）条目中的 `/` 替换为单个 `\`，并以单个 `\` 去除末尾目录分隔符；与 `$packageFiles`（发布包文件白名单）的单反斜杠表示一致。
- 新增 `project-tools/test-scripts/Test-PackageReleaseArchivePath.ps1`，以真实发布脚本生成 ZIP 并确认正斜杠 ZIP 条目可通过白名单检查。
- 新增 `project-tools/test-scripts/Test-F005ReleasePackage.ps1`，在系统临时目录生成并隔离解压发布包，输出载荷文件清单、校验 CRT（微软 C 运行时）DLL 哈希，并确认 EXE（可执行文件）启动后未立即退出。

## 根因与风险

PowerShell 单引号字符串中的反斜杠不是转义符。原代码中的 `\\` 实际为两个反斜杠，使 ZIP 的正斜杠路径规范化结果无法匹配使用单反斜杠的白名单。

本次仅改变白名单比较的路径表示，不改变 ZIP 安全检查；`Test-UnsafePath`（不安全路径检查）仍使用原始 ZIP 条目执行。架构、数据、权限、路由、依赖和发布状态均未改变。风险为低：后续发布脚本若改动条目生成规则，需重跑两份新增测试。
