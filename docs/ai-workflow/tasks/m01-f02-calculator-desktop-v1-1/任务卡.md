# M01-F02 | 计算器桌面化增强与个性化配置 v1.1

- Internal ID: `m01-f02-calculator-desktop-v1-1`
- Workflow version: `v1.1`
- Status: 开发收尾完成，待独立测试
- Business objective: 在不改变计算能力的前提下，使 Qt 计算器具备桌面程序图标、固定窗口、用户命名和可持久化的个性化外观。
- In scope: 同源 `.ico` 的 EXE/任务栏/窗口图标；600x800 固定窗口；首次用户名采集和标题更新；`calculator.ini` 中的用户名、主题和本地背景图路径；Ocean、Forest、Sunset 和自定义背景。
- Explicitly out of scope: `src/model` 计算逻辑、表达式规则、历史记录、科学计算、账户、网络、第三方依赖、发布和远程操作。
- Low-risk completeness items: 将图标加入 qmake 资源与 Windows RC；配置职责限定在 `ConfigManager`；Controller 编排配置，View 只接收输入并渲染。
- Users and business rules: 首次启动要求输入非空用户名；后续启动读取本地配置；窗口标题为“{用户名}的计算器”；选择预设主题清空自定义背景，选择本地图片切换为 `custom` 主题。
- Acceptance criteria: 可构建的 Release 程序具有统一图标和固定 600x800 窗口；用户名、主题和背景图可重启恢复；既有 Engine 用例仍可运行；部署目录含 Qt 运行时；运行时配置往返有可追溯证据。
- Dependencies and integration baseline: `master@4856482`，开发分支 `codex/calculator-desktop-v1.1`；Qt Widgets/qmake/MSVC 工具链。
- Allowed paths: `calculator.pro`、`resources/`、`src/config/`、`src/main.cpp`、`src/controller/CalculatorController.*`、`src/view/CalculatorUI.*`、`docs/agent.md`、`docs/business-context.md`、`docs/ai-workflow/`。
- Test requirements: Release 构建；Engine 独立构建与全量用例；部署目录检查；隔离运行时的首次用户名、重启恢复、三种主题、自定义背景、固定窗口和图标验收。
- Risk level and approval-needed actions: 低风险本地功能改动；无架构、权限、数据迁移或依赖变更。不得合并、打标、推送或部署。
- Open questions: 无；v1.1 运行时截图和完整命令输出未留存，交由独立测试补齐。

## Repair Decision 2026-08-05

- Delivery policy: the Release directory must start directly without a development environment. The MSVC x64 CRT is included as redistributable files in `resources/runtime/win-x64/` and copied beside the executable by the Release qmake post-link step.
- Installer policy: `vc_redist.x64.exe` remains an installation prerequisite when an installer is produced; it is not required to launch the unpacked Release directory.
- Scope impact: adds Microsoft redistributable runtime binaries under the already allowed `resources/` path and one qmake deployment step. No application dependency, architecture, permission, data, or calculation behavior changes.
- Verification: rebuild and deploy from a clean directory, set `PATH` to Windows system directories only, then complete the full GUI acceptance flow.
