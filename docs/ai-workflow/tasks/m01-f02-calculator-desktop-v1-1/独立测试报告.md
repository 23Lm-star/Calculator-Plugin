## 精确复现与修复交接

1. 在未安装/不可发现 MSVC CRT 的环境中，将 `PATH` 设为 `C:\Windows\System32;C:\Windows`。
2. 从 `C:\tmp\codex-m01-f02-independent-test\release\WangChenyangCalculator.exe` 启动发布 EXE。
3. 进程退出码为 `-1073741515`；`dumpbin /dependents` 显示它依赖 `MSVCP140.dll`、`VCRUNTIME140.dll` 与 `VCRUNTIME140_1.dll`。
4. 虽然 `windeployqt --compiler-runtime` 生成了 `vc_redist.x64.exe`，该 installer 未被执行，发布目录中没有这些 CRT DLL，故不能直接启动。

修复会话应确定交付约定：在发布前安装/引导安装 `vc_redist.x64.exe`，或按项目允许的发布策略提供相应 CRT。修复后必须重新从无开发工具链环境启动 EXE，并完整重跑所有 GUI 验收项及截图。不要把现有 `calculator.ini` 产物视为 GUI 验收替代品。
