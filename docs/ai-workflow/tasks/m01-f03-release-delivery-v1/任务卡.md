# M01-F03 | 发布交付物生成与部署脚本化

- Internal ID: `m01-f03-release-delivery-v1`
- Workflow version: `v1.1`
- Task card version: `v1.1`
- Status: 开发完成，待独立测试
- Business objective: 为“王晨扬的计算器”提供 Windows 10/11 可移植 ZIP 与简易安装包，使终端用户无需安装 Qt 开发工具链；Qt 运行时随应用目录提供，安装器自动补齐 Microsoft Visual C++ x64 运行库。
- In scope: 发布打包脚本、运行依赖检查、版本化 ZIP、PowerShell 快捷方式脚本、自动安装脚本、安装包、使用说明、交付物压缩和验证证据。
- Explicitly out of scope: 编译过程修改、应用业务代码、在线升级、远程发布、推送、部署。
- Dependencies and integration baseline: `integration@1ce0e9a`; Release 输入目录为 `build/v1.1-app/release/`，应包含 Qt 运行时、`platforms/qwindows.dll`、MSVC x64 CRT 与 `vc_redist.x64.exe`。
- Allowed paths: `scripts/release/`, `release/`, `artifacts/release/`, `docs/ai-workflow/`。
- Acceptance criteria:
  1. 生成带版本号的 ZIP，且不包含开发机绝对路径。
  2. ZIP 内有可重复执行的 PowerShell 桌面快捷方式脚本，指向应用 EXE。
  3. ZIP 内有 README，说明解压、环境要求、快捷方式和启动路径。
  4. 生成简易安装包，安装时复制到用户目录并自动创建桌面快捷方式。
  5. 安装器在复制应用和创建桌面快捷方式成功后，使用部署目录内的 `vc_redist.x64.exe /install /quiet /norestart` 自动安装 VC x64 运行库；退出码 `0`、`3010` 为成功，其他退出码必须失败并提示手动执行路径。
  6. 便携 ZIP 的 README 明确 Qt 运行时已随包提供，且可手动执行包内 `vc_redist.x64.exe`。
  7. 验证脚本解析、交付物运行时文件、VC 安装成功/需重启/失败分支、安装复制/快捷方式/启动回归及 ZIP 无开发机绝对路径。
- Risk level and approval-needed actions: 低风险本地交付变更；不得推送、部署、合并 `main` 或新增依赖。IExpress 在当前机器两次构建失败，故采用 Windows PowerShell 5 自带 `Expand-Archive` 的 Installer ZIP，不新增依赖。VC 运行库安装失败会阻止安装成功，用户可按错误信息手动执行部署目录内的安装程序。
- Open question: 无。终端用户无 Qt/MSVC 开发环境不是本次发布验收前置条件；独立测试应验证运行时文件与安装器分支行为。
