# 开发报告 | M01-F03

## 验收标准变更（2026-08-07）

- 移除“无 Qt/MSVC 开发环境的 Windows 10/11 机器”作为发布验收前置条件。
- 终端用户仍无需安装 Qt 开发工具链，Qt 运行时继续随应用目录交付。
- 安装器须在应用复制和桌面快捷方式创建成功后，自动运行部署的 `vc_redist.x64.exe`；`0` 与 `3010` 为成功，其他退出码必须报错并给出手动执行路径。
- 验收改为记录脚本解析、运行时文件交付、VC 安装三分支模拟、`-NoLaunch` 安装/快捷方式/启动回归和 ZIP 绝对路径扫描。

## Outcome

实现了可重复执行的 Windows 发布封装：`Package-Release.ps1` 从既有 Release 构建物白名单复制应用、Qt 插件、MSVC CRT 与 `vc_redist.x64.exe`，生成版本化便携 ZIP 和 Installer ZIP。便携包提供 `Create-DesktopShortcut.ps1`；安装包提供 `Install-Calculator.ps1/.cmd`，安装时写入当前用户目录、创建桌面快捷方式，并自动运行部署目录内的 VC x64 运行库安装程序。

## 本轮实现

- `Install-Calculator.ps1` 在应用复制和桌面快捷方式创建成功后，运行 `vc_redist.x64.exe /install /quiet /norestart`。
- 仅将退出码 `0` 和 `3010` 作为成功；`3010` 输出重启提示，其他退出码抛出包含退出码与手动执行路径的错误。
- 保留 `-NoLaunch`：它只禁止启动应用，不跳过 VC 运行库安装。
- `Package-Release.ps1` 将 `vc_redist.x64.exe` 加入必需运行时清单，缺失时打包失败。
- `release/README.md` 说明 Qt 运行时随包提供、安装器自动安装 VC 运行库，以及便携 ZIP 可手动执行 `vc_redist.x64.exe`。

## Repository payload delivery update (2026-08-08)

The former end-user flow required an externally generated `*-Installer.zip`. This implementation replaces that flow with a Git-tracked `release/Payload.zip`: a complete project checkout can run `scripts/release/Install-Calculator.cmd` directly. `Install-Calculator.ps1` uses only that repository-relative payload path. `Package-Release.ps1` remains the maintainer-only, source-relative payload rebuild command and uses a fixed package root plus an explicit archive whitelist.

`release/Payload.zip` was rebuilt successfully at 56,029,144 bytes with SHA-256 `87BE6060E0BB4BADBC0658FB162175F1310C48F388E71BF4641BDD0895A3E101`. All three release PowerShell scripts parsed with zero AST errors. The controlled-copy validation passed without `build` or `artifacts/release`; it verified payload locating, extraction, copy, desktop shortcut invocation, the `vc_redist.x64.exe /install /quiet /norestart` call, and `-NoLaunch`. The VC call was process-local simulated; no real VC runtime installation was executed.
